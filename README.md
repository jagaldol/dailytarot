# Daily Tarot

하루에 한 장, 타로 카드와 운세를 날짜별로 기록하는 개인용 Android 앱입니다.
홈 화면 위젯에서 오늘의 카드와 운세 한 줄을 함께 보여줍니다.

- 서버, 로그인, 네트워크 없이 동작합니다. 기록은 기기 안의 SQLite에 날짜별로 저장됩니다.
- 하루가 시작되면(기본 자정) 그날의 카드 뒷면이 놓이고, 눌러서 뽑거나 정한 시간(기본 오전 8시)에 자동으로 뽑습니다. 같은 날에는 다시 뽑지 않습니다.
- 기본 운세는 Lifebase 카드 사전의 정·역방향 문구 156개를 그대로 사용합니다.
- 원하면 Lifebase의 Journal 폴더를 연결할 수 있습니다. 연결하면 그날 일지에 적힌 카드와 운세를 읽어 와 앱과 위젯을 자동으로 갱신합니다.

## 오늘의 카드

설정 → 오늘의 카드에서 두 가지 시간을 정합니다.

- **하루 시작 시간**(기본 오전 12:00): 이 시간 전에는 어제 카드를 그대로 보여주고, 지나면 새 날의 카드(또는 카드 뒷면)로 바뀝니다.
- **자동으로 뽑기**(기본 켜짐)와 **자동으로 뽑는 시간**(기본 오전 8:00): 켜져 있으면 그 시간까지 카드를 뽑지 않았을 때 대신 뽑습니다.
  Lifebase를 연결하면 자동으로 꺼지며, 설정에서 다시 켤 수 있습니다.

| 오늘 카드가 없을 때 | 앱 | 위젯 |
| --- | --- | --- |
| 하루 시작 전 | 어제 카드 + "어제의 카드" 안내 | 어제 카드 |
| Lifebase 미연결 | 카드 뒷면, 누르면 바로 뽑힘 | 카드 뒷면 + "오늘의 카드를 뽑아주세요"(자동 뽑기가 켜져 있으면 "오전 8:00에 오늘의 카드가 뽑혀요") |
| Lifebase 연결 | 카드 뒷면, 눌러도 뽑히지 않음 | 카드 뒷면 + "Lifebase에 오늘의 카드가 아직 등록되지 않았어요" |

위젯의 "오늘의 카드를 뽑아주세요"를 누르면 앱이 오늘 화면으로 열리면서 카드를 바로 뽑아 뒤집어 보여줍니다.
다른 상태의 위젯을 눌러도 항상 오늘 화면이 열립니다.

오늘 처음 보는 카드는 뒷면을 눌러야 펼쳐집니다. 이미 본 카드도 앱을 새로 열 때, 그리고 10분 이상 다른 곳에 있다가
돌아올 때 뒷면에서 한 번 뒤집히며 나타납니다(잠깐 나갔다 오거나 탭을 오가거나 화면을 돌릴 때는 다시 뒤집지 않습니다).

Lifebase에 연결된 동안에는 화면 아래의 작은 **카드 직접 뽑아보기**로만, 한 번 더 확인한 뒤 뽑을 수 있습니다.
이렇게 뽑은 카드도 그날 일지가 들어오면 일지 내용으로 바뀝니다.

## 기록 규칙

| 상황 | 결과 |
| --- | --- |
| 오늘 기록이 있음 | 그대로 유지. 재시작·위젯 추가로 다시 뽑지 않음 |
| 앱을 열지 않은 날 | 나중에 채우지 않음 |
| Lifebase 연결, 그날 일지에 운세가 있음 | 일지의 카드·방향·운세로 교체(직접 뽑은 카드 포함) |
| 일지의 운세 문구만 수정 | 같은 날짜 기록을 갱신 |
| 일기·일정만 수정 | 운세 hash가 같으므로 아무것도 바꾸지 않음 |
| 파일 삭제·권한 상실·작성 중인 파일 | 마지막 정상 기록 유지 |
| 연결 해제 | 가져온 기록은 남음("Lifebase 일지에서 가져옴"으로 출처 표시) |
| 기록 지우기 | 앱에서 뽑거나 고른 기록은 언제든 지울 수 있음. Lifebase에서 불러온 기록은 연결을 해제했을 때만 지울 수 있음(연결 중에는 다시 불러와지므로). 기록 상세의 휴지통, 또는 설정의 전체 지우기 |

기록에는 저장 당시의 문구가 들어 있습니다. 나중에 카탈로그나 일지가 바뀌어도 지난 기록이 몰래 바뀌지 않습니다.
Lifebase 기록에는 `## 오늘의 운세` 섹션의 원문만 저장하며 일기·일정·메모는 읽어도 저장하지 않습니다.
카드 직접 고르기(카드 목록에서 선택)는 Lifebase에 연결되지 않았을 때만 쓸 수 있습니다.

이전 버전에서 고른 카드가 있으면 첫 기록을 그 카드로 시작합니다. 이 기록은 한 번 “새로 뽑기”로 바꿀 수 있습니다.

## Lifebase 연결

설정 → **Journal 폴더 연결**에서 Lifebase 폴더나 그 안의 `Journal` 폴더를 고릅니다.
Storage Access Framework 읽기 권한만 받으며 일지에 쓰지 않습니다.
Syncthing을 쓰는 경우 보통 `Documents/lifebase`입니다.

- 연결 직후 최근 월부터 과거 기록을 한 번 가져옵니다. 설정에서 진행 상황을 보고 중지할 수 있습니다.
- 확인 시점과 읽는 양:

  | 언제 | 읽는 범위 |
  | --- | --- |
  | 앱을 열 때(위젯을 눌러 열 때 포함), 설정 → 지금 확인 | 오늘 + 지난 7일, 파일을 모두 다시 읽음 |
  | 오늘 운세를 아직 못 가져온 동안 15분마다 | 오늘 + 어제. 크기·수정 시각이 지난번과 같은 파일은 열지 않음 |
  | 매일 자정 직후 한 번 | 위와 같음(새 날짜의 15분 확인 시작) |
  | 하루 시작 시간·자동으로 뽑는 시간(위젯이 있을 때) | 위젯을 카드 뒷면이나 오늘 카드로 전환 |

  오늘 운세를 가져오면 15분 확인은 멈추고 다음 자정까지 쉽니다. 평소에는 하루 몇 번, 파일 1~2개만 읽습니다.
  Android 절전 정책 때문에 예약 확인은 늦어질 수 있습니다. 화면과 위젯은 항상 기록의 날짜를 함께 보여줍니다.
- 지원 형식: `tarot-card`·`tarot-reverse` frontmatter와 `## 오늘의 운세`의 `[!quote]` 콜아웃.
  한 줄+키워드+본문인 현재 형식과 키워드만 있는 옛 형식을 모두 읽습니다.
  옛 형식에는 해석을 지어내지 않고 기본 해석을 따로 표시합니다.
- 카드·방향이 본문과 frontmatter에서 다르거나, 같은 키가 두 번 있거나, 알 수 없는 카드면 갱신을 보류합니다.

## 위젯

카드가 주인공인 투명 위젯입니다. 처음 추가하면 한 화면을 채우는 크기로 놓입니다. 5열 런처에서는 5×6, 4열 런처(Pixel 기본)에서는 4×6이며, 2×2까지 줄일 수 있습니다.
칸 크기에 맞춰 카드를 최대한 크게 그리고, 남는 자리에 작은 캡션(날짜·카드 이름과 운세 한 줄)을 붙입니다.

- 세로로 길거나 화면 전체 크기: 카드 아래에 캡션
- 가로로 긴 크기: 카드 옆에 캡션
- 아주 작은 크기(2×2 등): 카드만

운세는 잘라서 보여주지 않습니다. 자리가 모자라면 글자를 13 → 12 → 11 → 10sp로 줄여 보고,
그래도 들어가지 않을 때만 캡션 없이 카드만 보여줍니다. 필요한 줄 수는 위젯 크기와 글꼴 배율로 미리 계산합니다.
캡션만 반투명 배경을 깔아 어떤 배경화면에서도 읽히게 했습니다.
한국어는 어절 단위로 줄바꿈합니다. RemoteViews가 줄바꿈 설정을 지원하지 않아, 낱말 안에 보이지 않는 word joiner를 넣었습니다.
모든 위젯이 같은 날짜의 같은 기록을 보여주고, 누르면 앱이 열리면서 Lifebase도 다시 확인합니다.

## 백업

기록은 이 기기에만 있습니다. 설정에서 JSON 파일로 내보내고 새 기기에서 복원할 수 있습니다.
복원은 비어 있는 날짜만 채우고 기존 기록을 덮어쓰지 않습니다.
Android 자동 백업에는 기록 DB와 설정만 포함하며, Lifebase 폴더 권한은 제외합니다. 복원 후 폴더를 다시 연결합니다.

## 실행

- Android 7.0(API 24) 이상
- JDK 21, Android SDK Platform 37.0, Build Tools 36.0.0
- Android Studio에서 프로젝트를 열어 SDK를 설정하거나, `local.properties`에 `sdk.dir`을 지정합니다.

```sh
./gradlew :app:assembleDebug
./gradlew :app:installDebug
adb shell am start -n com.jagaldol.dailytarot/.MainActivity
```

## 검증

```sh
./gradlew :app:testDebugUnitTest :app:lint :app:assembleRelease
./gradlew :app:connectedDebugAndroidTest  # 테스트용 기기/에뮬레이터 필요
python3 tools/check_assets.py
python3 tools/extract_lifebase_catalog.py /path/to/lifebase --check
```

기기 테스트는 앱 데이터(오늘 기록, Lifebase 연결)를 바꾸므로 테스트용 기기에서 실행합니다.
릴리스 빌드에는 R8 코드 및 리소스 축소를 적용합니다. 서명 키는 저장소에 없습니다.

## 구조

- `model/`: 78장 덱, API 24에서도 쓰는 날짜 타입 `Day`, 날짜별 기록 `DailyReading`
- `data/ReadingStore.kt`: 날짜를 기본키로 하는 SQLite 저장소와 변경 관찰
- `data/ReadingRepository.kt`: 하루 한 장, 출처 우선순위, 연결 세대 확인을 담당하는 단일 writer
- `data/FortuneCatalog.kt`: `assets/default_fortunes.ko.json`의 기본 운세 156개
- `data/SettingsStore.kt`: 기준 시간대·카드 공개 상태(백업 대상)와 Lifebase 연결(백업 제외)
- `data/lifebase/`: 일지 운세 파서, SAF 읽기, 오늘/최근 7일 동기화와 과거 기록 가져오기
- `work/`: 주기 확인과 과거 기록 가져오기 WorkManager 작업
- `widget/`: 크기별 Glance 위젯
- `ui/`: 오늘·기록·설정·카드 고르기 화면과 테마

새 라이브러리 의존성은 추가하지 않았습니다. 날짜별 DB는 Room 대신 플랫폼 SQLite를,
JSON은 단위 테스트에서도 도는 작은 내장 파서를 사용합니다.

## 도구

- `tools/check_assets.py`: 카드 이미지 156개와 기본 운세 카탈로그 검사
- `tools/extract_lifebase_catalog.py`: Lifebase 카드 사전에서 기본 운세를 다시 추출하거나 비교
- `tools/make_launcher_icons.py`: API 24–25용 런처 아이콘을 adaptive icon과 같은 도형으로 생성
- `tools/fetch_rws_images.sh`, `convert_pngs_to_webp.sh`, `make_thumbs.sh`: 카드 이미지 준비(`cwebp` 필요)

이미지 출처와 공개 전 남은 확인 사항은 [ASSETS.md](ASSETS.md)를 참고하세요.
검증 내역은 [docs/verification.md](docs/verification.md)에 기록합니다.
